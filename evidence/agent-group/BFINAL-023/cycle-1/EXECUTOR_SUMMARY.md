## H7 机理（本轮新发现，源码+代数推导）

动量方程构造 `... == −fvc::grad(p)`（operator== 语义 source += V·su）
使 UEqn 源含 −∇p·V 一次；`solve(UEqn == −fvc::grad(p))` 的第二个
−∇p 只进临时拷贝。定点代数给出 HbyA = U + rAtU·∇p（与 NS.H:1039
`U = HbyA − rAtU*grad(p)` 互证），故真
phi = interp(U)·Sf + **interp(rAtU·∇p)·Sf** − kf(p_n−p_o)；生产
J 的 P 行（与离线仪器）只建了 −kf(p_n−p_o)。值级（3.01→2.60%，
反号 3.80% 恶化）与切线（corr −0.996）双向证实。
